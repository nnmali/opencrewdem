Below is the complete OpenCrew setup, in order, starting with the Python code, then Git, and finally GitHub Actions (CI).

You already have the GitHub repository `nnmali/opencrewdem` and have successfully run CI once. These instructions show the complete process so you can follow it from the beginning or check each file.

# **1. Open your project in the terminal**

```
cd ~/opencrewdem
```

Activate your virtual environment:

```
source venv/bin/activate
```

# **2. Create the Flask application**

Open the application file:

```
nano app.py
```

```

import pytestfrom app import app, team@pytest.fixturedef client():    original_team = team.copy()    app.config["TESTING"] = True    with app.test_client() as client:        yield client    team.clear()    team.extend(original_team)def test_home(client):    response = client.get("/")    assert response.status_code == 200    assert response.json["message"] == "Welcome to OpenCrew"def test_health(client):    response = client.get("/health")    assert response.status_code == 200    assert response.json["status"] == "healthy"def test_team(client):    response = client.get("/team")    assert response.status_code == 200
```

# **9. Create the GitHub Actions CI workflow**

Create the hidden GitHub Actions directories:

```
mkdir -p .github/workflows
```

Create the workflow file:

```
nano .github/workflows/ci.yml
```

Paste this complete YAML:

```

name: OpenCrew CI

on:
  push:
    branches:
      - main

  pull_request:
    branches:
      - main

jobs:
  test:
    name: Test OpenCrew
    runs-on: ubuntu-latest

    steps:
      - name: Checkout code
        uses: actions/checkout@v4

      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: "3.12"

      - name: Install dependencies
        run: |
          python -m pip install --upgrade pip
          pip install -r requirements.txt

      - name: Run tests
        run: pytest -v

```

Save and exit.
